# Phase Memory Index

Each phase owns one memory folder. Phase agents update their folder during implementation and summarize changes in their output file.

## Phase Folders

- `SA-00/`: skill acquisition and validation memory.
- `SP-00/`: product, risk, repo contract memory.
- `SP-01/`: local app foundation memory.
- `SP-02/`: video/audio capture memory.
- `SP-03/`: media/transcription memory.
- `CRIT-01/`: provenance gate memory.
- `SP-04/`: video understanding memory.
- `SP-05/`: memory/RAG memory.
- `SP-06/`: summaries/sources memory.
- `SP-07/`: tutor agent memory.
- `SP-08/`: gated improvement memory.
- `SP-09/`: hardening/packaging memory.
- `SP-10/`: cloud sync memory.
