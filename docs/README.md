# Lagoon Documentation

> [!IMPORTANT]
> `docs/` is the short path to understanding Lagoon. Update the relevant note when a feature, decision, or verification step changes.

## Documentation Dashboard

| Area | Purpose | Start here |
| --- | --- | --- |
| Plans | The agreed build sequence and MVP boundaries | [MVP Build Plan](plans/mvp-build-plan.md) |
| Decisions | Short records for choices that would otherwise be rediscovered | `decisions/` |
| Lessons | Beginner-friendly explanations of finished slices | `lessons/` |
| Memory | Folder and component maps for future coding agents | `memory/` |
| Run logs | Brief records of verification results | `run-logs/` |

## Documentation Rules

- Keep documents concise, GitHub-readable, and tied to real paths and commands.
- Record a decision when changing a provider, data boundary, or project structure.
- Update the matching memory note when adding or changing a code folder.
- Do not put API keys, private transcripts, or real user media in documentation or run logs.

## Stop Point

This commit creates the documentation and project layout only. It does not implement the app, install dependencies, or configure any paid service.
